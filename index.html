Les trois règles de remplissage

1

Règle de Klechkowski (ordre énergétique)

La règle de Klechkowski (ou règle de Madelung) établit l’ordre de remplissage des orbitales électroniques selon la somme n + ℓ, puis selon n en cas d’égalité. Elle permet de déterminer la configuration électronique des atomes dans leur état fondamental. Principe fondamental : la règle (n + ℓ), n : nombre quantique principal (n ≥ 1), ℓ : nombre quantique azimutal (0 ≤ ℓ ≤ n − 1), Les sous-couches sont classées par ordre croissant de (n + ℓ). Si deux sous-couches ont la même valeur de (n + ℓ), celle avec le plus petit n se remplit en premier.
